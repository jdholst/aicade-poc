# Resolve mechanics through contract coverage

Sparkline will resolve creator-requested Mechanic Intents by comparing their structured requirements with declared Built-in Mechanic Contracts, not by keyword routing or model confidence alone. AI may interpret language and propose a built-in or composition, but Sparkline accepts that proposal only when deterministic coverage accounts for every meaningful requirement; uncovered valid behavior proceeds to generated mechanic work, while unavailable primitives produce an explicit capability gap.

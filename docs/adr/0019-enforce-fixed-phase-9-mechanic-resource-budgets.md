# Enforce fixed Phase 9 mechanic resource budgets

Phase 9 will apply one pragmatic Sparkline-owned Mechanic Resource Budget profile per generated mechanic through the Generation Constraint Set, covering owned objects, operation rates, timers, subscriptions, gameplay signals, state, callback execution, and repeated failures. Generated contracts may state expected resource use for validation but cannot raise their limits; budget violations become structured failure evidence, while adaptive quotas and additional profiles wait for evaluation evidence.

# Test generality with a post-freeze holdout mechanic

Phase 9 will establish an Evaluation Freeze after its known success cases pass, then select a previously unseen Holdout Mechanic and external acceptance observations. Generic defect fixes remain permitted, but adding holdout-specific routing, prompts, schemas, helpers, or orchestration invalidates an unchanged-pipeline success claim; a genuinely missing primitive produces a Capability Gap, and any later expansion is evaluated as a new capability version.

# Constrain mechanic count outside the single-mechanic pipeline

The Phase 9 limit of one generated mechanic per game-generation run will be enforced by the Generation Constraint Set at a Mechanic Generation Coordinator, not hardcoded into the reusable single-mechanic pipeline. This preserves an honest Phase 9 simplification while allowing the architecture to admit multiple mechanic requests later, when composition, dependency, budget, interaction, and repair semantics are deliberately addressed.

# Use a restricted Mechanic Config DSL

Generated Mechanic Extension manifests will define their configuration contracts through a restricted Sparkline-owned DSL rather than hand-authored mechanic profiles, executable validation code, or unrestricted JSON Schema. This lets AI introduce genuinely new mechanic configuration while Sparkline can validate Game Specs before executing generated code, impose complexity and policy limits, derive repair errors and future editor controls, and version the supported language deliberately.
